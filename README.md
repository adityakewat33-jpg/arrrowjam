# Arrow Jam: Escape & Untangle 🎯

A satisfying minimalist neon spatial logic puzzle game built with native Android (Kotlin).

## 🚀 Features
- **200+ Levels**: Intelligently crafted progressive puzzle boards with dynamic shape scales.
- **Dynamic Over-The-Air (OTA) Level Sync**: New levels added to `levels.json` in this repository automatically sync to players' phones in the background!
- **8 Handcrafted Themes**: Cyber Neon, Synthwave 80s, Emerald Matrix, Solar Flare, Nordic Frost, Sakura Bloom, Obsidian Gold, and Midnight Abyss.
- **Google Mobile Ads (AdMob) Integrated**:
  - Banner ads on Home Screen and below the in-game action bar.
  - Rewarded video ads for +1 Extra Life, Free Hints, Coin Shop, and Game Over Revive.
- **40 Milestone Achievements**: Full-page showcase with instant coin rewards.
- **In-Game Coin Economy & Store**: Purchase Hint Bundles and unlock custom neon palettes.

## 📁 Dynamic Remote Levels
Add new levels directly to [`levels.json`](./levels.json). Any device running Arrow Jam will automatically download them when connected to the internet.
